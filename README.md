A single short pickup line an AI agent could actually say out loud to a
person — written to land on its own, with no setup, in one breath.

`main.ts` (Node 22, readable TypeScript, no dependencies) writes the line to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with a read-back
gate that refuses anything outside 1–200 characters or only whitespace.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/perfect-pickup-line-out node main.ts
```
